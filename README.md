## 🔢 How the writeup count stays honest

The "CTF WRITEUPS" counter is **not** a hard-coded number. It is derived from the
`zudio-infosec/ctf-writeups` repository:

- every `*.md` file is counted at **any depth** (repo root *and* all sub-folders)
- every `README.md` is subtracted (those are index docs, not writeups)
- the live page reads the recursive git-tree API; the static fallback number is
  regenerated by the **Sync writeup count** GitHub Action on every push to
  `ctf-writeups` (and daily), so both always agree

To refresh it locally:

```bash
git clone https://github.com/zudio-infosec/ctf-writeups
python3 scripts/count_writeups.py --repo ../ctf-writeups --html index.html --list
```
